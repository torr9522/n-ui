# x-ui 维护说明

## 2026-04-22 修复说明

### 一、本轮源码修复内容
1. 安装地址修复  
安装完成后，面板访问地址优先使用公网 IPv4，避免默认展示内网 IP。

2. 协议稳定性修复  
针对 `mixed`、`dokodemo-door`、`socks`、`http`、`tunnel` 做了模型与页面容错修复，主要覆盖：
- 认证字段与账户数组缺失时的空值保护；
- `dokodemo/tunnel` 默认参数容错（地址、端口、网络）；
- 不支持传输层协议时不再提交无效 `streamSettings`；
- 协议常量统一（`dokodemo-door` 小写）。

3. 菜单修复  
修复菜单选项 `7` 读取设置失败问题，并补齐相关命令参数支持与脚本函数名错误。

4. 本轮追加修复（认证展示与开关）
- `socks` 在 `noauth` 模式下，详情页不再显示用户名/密码；
- `http` 新增“密码认证”开关，支持 `password/noauth`；
- `http` 在 `noauth` 模式下不再写入账号字段；
- 用户名/密码展示 getter 增加判空，避免空数组报错。

### 二、验证结果
1. `go test ./...` 通过。  
2. 服务状态验证通过：`x-ui` 为 `active` 且 `enabled`。  
3. 接口实测通过：
- 可创建 `socks` + `noauth`；
- 可创建 `http` + `noauth`；
- 入站创建后配置字段与预期一致。
